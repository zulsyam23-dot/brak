# brak-polyglot

Modul tercanggih di Brak untuk dukungan multi-bahasa.

## Kegunaan
Memungkinkan bahasa yang berbeda (misalnya Brak dan LitLang) untuk saling memanggil fungsi satu sama lain tanpa ada beban performa (Zero-overhead FFI). Ini dilakukan dengan melakukan normalisasi antarmuka fungsi di level LIR.
